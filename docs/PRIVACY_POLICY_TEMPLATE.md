## Data Stride handles

Stride processes daily step totals, estimated activity metrics, app preferences, and—only when a user starts a walk—location points needed to calculate and display that route. An active walk is written locally first. Stride does not contain advertising or third-party analytics SDKs.

## Optional cloud sync

If a user creates an account, Stride sends account identifiers, completed walk summaries and routes, daily summaries, goals, and preferences to the configured Supabase project over encrypted transport. It does not upload each live GPS sample as it is collected. Describe Supabase as a processor and add its applicable location and terms here: [DETAILS].

## Permissions

Motion permission supplies step totals where supported. Foreground location is used during a walk. If the user explicitly enables background recording and grants background location, location collection may continue while an active walk is in progress with the screen locked or another app open. It stops when the walk is paused, finished, or discarded.
